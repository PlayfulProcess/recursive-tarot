# Archive — superseded deck grammars

These grammars were built on recursive.eco **before this repo became the canonical tarot library**, and each was later superseded by a repo deck. They are preserved here for history, then deleted from the recursive.eco database and channel listings on **2026-08-29** so the app's tarot channel stays 1-1 with this repo.

Each `grammar.json` is the full document as exported from the app, with an `_archived` block recording its original recursive.eco id and dates.

| Archived deck | Built | Superseded by (repo slug) |
|---|---|---|
| `etteilla-iii-first-version` | Jan 2026 | `etteilla-iii-oracle-des-dames` (Grand Jeu de l'Oracle des Dames) |
| `rws-archetypal` | Dec 2025 | `rider-waite-smith-pictorial-key` |
| `rws-golden-dawn-style` | Apr 2026 | `golden-dawn-book-t-tarot` |
| `sola-busca-first-version` | Dec 2025 | `sola-busca-tarot` |
| `tarot-de-marseille-public-domain` | Dec 2025 | `tarot-de-marseille-conver` (Nicolas Conver 1760) |
| `tarot-of-all-tarots` | Mar 2026 | `all-decks-many-lenses` (the meta grammar) |

The first five were early single-deck builds from before the repo's historical-sourcing standards (dated attributions, provenance notes). `tarot-of-all-tarots` was the first attempt at a cross-deck collection and is the direct ancestor of "The Tarot — All Decks, Many Lenses."

Nothing in this folder is served by the site or imported by recursive.eco: the channel manifest glob (`tarot/*/grammar.json`) does not descend into `_archive/`.
