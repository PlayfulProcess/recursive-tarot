## 4. Public-domain deck survey

The rule of thumb: **the design** of any deck older than ~1900 is PD everywhere. **The
scan** may carry terms. Most US museums (NGA, Met, Yale, Cleveland) release PD scans as CC0
or without restriction. French and UK institutions (BnF/Gallica, British Museum) allow free
non-commercial use but charge for commercial use. Modern *restorations*, recolourings and
reprints (Flornoy, Kondor, Reality Publishing, U.S. Games 1971, Lo Scarabeo) are new works
with their own copyright. Never scan those.

## 5. Print / Amazon plan

**What exists already:** TGC drafts for 8 decks plus a Conver proof (private). A 26-card
sampler proof was printed; docs/TGC-STORE-AUDIT.md says its Justice card "fills the card
properly". The TGC rule: **you must buy one copy before you can Publish**
(print/SHOP-PLAN.md). There is a book pipeline (`scripts/generate_book.py` → 7×10 PDF for
KDP/IngramSpark).

**Key fact:** Amazon's own print services (**KDP**) make **books only**. Card decks cannot
go through KDP, and Merch on Demand does apparel and accessories, not cards. **Handmade**
requires products made by the seller, so print-on-demand doesn't qualify. A **deck on
Amazon** therefore means a **Seller Central** listing ($39.99/mo Professional plan, plus a
~15% referral fee, approx.). You fulfil it via **FBA** (ship a small batch of printed decks
to Amazon) or by merchant fulfilment. It needs a UPC/GS1 barcode or a GTIN exemption
(or Brand Registry, which needs a trademark).
(Sources: KDP printing cost https://kdp.amazon.com/en_US/help/topic/G201834340; Printful on
GTIN exemption https://www.printful.com/blog/how-to-sell-on-amazon-with-printfuls-integration;
DriveThruCards tarot costs https://help.drivethrupartners.com/hc/en-us/articles/12780747991575-Printed-Card-Formats-Costs.)

**Minimal-owner-time path (recommended): the guidebook first, the deck second.**

*Phase A — a KDP book (no physical proof required to publish). Claude can do steps 1–4:*
1. Choose the title: e.g. *The Rider-Waite-Smith Tarot: A Card-by-Card Guide
   (Illustrated)*, or the History-of-Tarot course book. KDP's public-domain rule says a book
   built on PD content must be **differentiated** (original annotations, or ≥10 original
   illustrations) and labelled "(Annotated)" / "(Illustrated)" in the title
   (https://kdp.amazon.com/en_US/help/topic/G200743940). The course prose is original, so
   it qualifies. Be ready to prove you own text that is also on the web (link the repo and
   site).
2. Run `python scripts/generate_book.py --pdf`. Add front matter with **per-image credits**
   (see P3) and **only commercially clean images**: RWS, Commons PD, Yale, NGA/Met. No
   Gallica or BM images unless licensed.
3. Cover: KDP Cover Creator, or a PD card plate plus the spiral mark.
4. Costs (approx., US): premium colour = $1.00 + $0.065/page, so 150 pp ≈ $10.75/copy.
   Standard colour = $1.00 + $0.0255/page, so ≈ $4.83. Royalty is 60% of list minus
   printing, so $24.99 on standard colour ≈ **$10/copy**. Free KDP ISBN.
5. **Owner (≈30 min):** create the KDP account (tax interview), upload, check the online
   previewer, and publish. *Optional proof:* KDP proof copies cost printing + shipping and
   can be ordered at the same time. Publishing does not have to wait for them.

*Phase B — the card deck (needs one physical copy):*
1. Choose one deck with clean rights: the **Golden Dawn/RWS** flagship (clean, print PASS,
   already staged). Leave out Viéville/Paris/Conver until P2 is resolved.
2. **The minimal proof step:** in TGC, run **Proof All** on the Golden Dawn draft (faces
   were re-uploaded 2026-07-30, which reset the digital proof). Then **order ONE copy**,
   about $24 (docs/TGC-STORE-AUDIT.md). That single purchase *is* both the quality proof
   and the publish unlock. Everything else can be done before it arrives: box text,
   colophon with credits, the shop page copy, and the KDP book.
3. When it arrives, check colour, cut and the back. Then **Publish**, paste the URL into
   `print-products.json` (`status: live`), and the site's Buy button goes live.
4. **Amazon for the deck (later, optional):** order 10–20 decks at TGC/MPC bulk pricing
   (MPC and QPMN have no minimums; DriveThruCards ≈ $18.72 for a 78-card deck at base
   price). Buy GS1 UPCs, open Seller Central, send to FBA, and link the listing to the KDP
   guidebook. This is only worth it once the TGC listing shows demand.

## 6. Autonomous-improvement workflow (skill draft)

1. **Start:** `git switch -c claude/<repo>-audit-<date>`. Never stash, reset or commit the
   owner's WIP. On OneDrive mounts use `GIT_OPTIONAL_LOCKS=0` and
   `-c core.autocrlf=true -c core.createObject=rename`, and move leftover locks into
   `.git/claude-stale/`.
2. **Read** the CLAUDE.md files (root + repo), README, BACKLOG and the corrections queue.
   Obey them.
3. **Checks:** the repo gate (`check_all.py` here), a local-link resolver, img-alt scan,
   `node --check` on edited inline scripts, JSON parse on edited JSON.
4. **May commit** (one concern per commit, evidence in the message): broken links/paths;
   typos; alt text; factual fixes that cite a source *and* match the repo's own dossiers;
   missing attribution/licence lines; doc lines that contradict CLAUDE.md.
5. **Must propose instead:** content rewrites, scholarly debates, design and UX, new
   features, pricing/vendors, anything in `_private`/secrets/CNAME/workflows/licences,
   deletes, and edits to files that have real (non-EOL) uncommitted changes.
6. **Hand-off:** one `docs/AUDIT-<date>.md` (commits, table, proposals), committed last.
   The owner reviews with `git log main..<branch>` and `git diff main..<branch>`, then
   cherry-picks or merges.
7. **Rollback:** `git switch main && git branch -D <branch>`. Nothing was pushed.
